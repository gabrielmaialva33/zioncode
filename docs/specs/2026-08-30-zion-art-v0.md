# Zion Art grammar v0

Date: 2026-08-30

Status: experimental compiler contract. Version 0 is deliberately not a wire
format and may change while visual quality is explored.

## Purpose

Zion Art converts UTF-8 content and a compact semantic profile into a
deterministic visual genome and RGB8 PNG. It answers “how should this content
look?” It does not answer “how are the exact bytes hidden and recovered?”

That boundary is normative for the experiment:

- `zion-art` owns content-derived visual identity;
- `zion-arc` owns compression, secrecy, authentication, and exact-PNG ARC v1;
- `zion_arc::screen_lab` remains an unstable host-only transport experiment;
- future screenshot beacon and block-channel formats require separate specs.

Research rationale: [algorithm review](../research/2026-08-30-zion-art-algorithm-review.md).

## Inputs

The compiler accepts:

- non-empty UTF-8 content, at most 16 MiB;
- raster width and height in `64..=4096`; and
- eight signed semantic axes quantized to `-1000..=1000`.

The canonical axis order is:

1. warmth;
2. motion;
3. density;
4. tension;
5. intimacy;
6. transcendence;
7. order; and
8. radiance.

This vector is model-independent. A person, rules engine, or pinned local model
may produce it. A future model frontend must record its model hash and
preprocessing version; the renderer must never infer that provenance.

## Content structure

Version 0 measures byte, Unicode scalar, word, sentence, non-empty line, and
paragraph counts. It also measures lexical diversity, ASCII punctuation
density, and an eight-bin normalized sentence-cadence vector.

The direct BLAKE3 content hash identifies the exact compiler input. A separate
domain-separated BLAKE3 visual seed covers:

- content hash;
- all semantic axes;
- cadence bins; and
- word and sentence counts.

Semantic changes therefore alter the art without altering content identity.

## Genome

The inspectable v0 genome contains:

- grammar version;
- content hash and visual seed;
- semantic profile and structural measurements;
- four RGB palette colors;
- one of eight flow directions;
- layer count;
- texture scale; and
- flow period.

The renderer uses only fixed-width integer operations. Floating-point
transcendentals, randomized process state, wall-clock time, and platform PRNGs
are forbidden from grammar output.

## Renderer

The initial renderer combines:

- three octaves of seeded, integer-interpolated value noise;
- a cadence-modulated directional flow field;
- a content-derived macro current;
- semantic order/disorder blending;
- content-derived HSV palette construction;
- restrained highlight contours, depth shaping, grain, and vignette.

The renderer is a first visual grammar, not a claim of finished artistic
quality. Its purpose is to establish stable compiler boundaries and measurable
content sensitivity before a shader or learned renderer is introduced.

## Required invariants

- Same content, dimensions, semantic profile, grammar version, and binary must
  produce identical PNG and raster bytes.
- A content-byte change must change the content hash and visual seed.
- A semantic-only change must preserve content hash and change visual seed.
- PNG decode must reproduce the emitted RGB raster exactly.
- Existing output paths are not replaced by the CLI.
- No semantic profile or visible artwork is treated as proof of exact content.
- No hidden-payload format or screenshot-survival claim is implied by v0.

## CLI

```bash
cargo run -p zion-cli -- art-render INPUT \
  --output artwork.png \
  --width 1080 \
  --height 2340 \
  --warmth -420 \
  --motion 680 \
  --density 360 \
  --tension 240 \
  --intimacy -180 \
  --transcendence 760 \
  --order 310 \
  --radiance 420
```

The semantic flags default to zero, enabling deterministic structural
experiments before a model frontend exists.

The checked-in reference render is
[`docs/results/assets/zion-art-v0-readme.png`](../results/assets/zion-art-v0-readme.png).
It is a 1080×2340 compiler artifact generated from `README.md`, not a visual
quality target. Its RGB raster BLAKE3 is
`5b2f37ee4193782c637b4a0cad70895415c9a1825b86931919154ee5300309f2`.

## Exit criteria for v1 consideration

Version 0 must not be promoted until:

1. three substantially different full books produce recognizable but related
   visual identities under independently reviewed semantic profiles;
2. the visual grammar has exact golden raster vectors;
3. macro parameters have documented sensitivity and no abrupt spatial seams;
4. the robust-beacon experiment recovers identity and geometry from real A57
   screenshots; and
5. the visual grammar and transport channel can evolve independently.
